Uparshop

Plataforma de Comercio Electrónico

Resumen del Proyecto

Uparshop es una plataforma de comercio electrónico desarrollada como un proyecto académico colaborativo. El objetivo principal fue construir un backend robusto, escalable y seguro capaz de gestionar el inventario, usuarios y transacciones de una tienda virtual moderna.

El Problema

El problema real del mercado es el alza abrupta de precios; es decir, los comercios de tecnología suelen subir exageradamente los costos, sobre todo en componentes de PC, afectando directamente al consumidor final y limitando el acceso a equipos de calidad.

La Solución

Para resolver esto, decidí diseñar el backend utilizando Clean Architecture. Esto permitió separar las reglas de negocio de la infraestructura (bases de datos y endpoints web).

Utilicé FastAPI por su altísimo rendimiento y su validación automática de datos. Para la seguridad, implementé JSON Web Tokens (JWT), asegurando que solo usuarios autenticados puedan realizar compras o acceder a rutas protegidas.

Lo que desarrollé (Mi Rol)

  • Diseñé e implementé la API REST desde cero usando Python y FastAPI.
  • Creé el modelo relacional de la base de datos en MySQL y escribí las consultas eficientes.
  • Desarrollé operaciones CRUD completas para la gestión de productos, categorías y cuentas de usuario.
  • Integré el sistema de login y seguridad basado en tokens JWT.
  • Manejé el versionamiento del código trabajando en equipo mediante Git y GitHub.

Tecnologías Utilizadas

Python FastAPI MySQL JWT Git / GitHub Clean Architecture
